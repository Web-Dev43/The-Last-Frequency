# The Last Frequency

A phone-friendly, browser-based cinematic 3D horror mystery built with Babylon.js.

## Current prototype

The first milestone is an original real-time 3D opening sequence:
- A quiet apartment at night
- A cinematic camera move through the room
- A radio signal at 3:17 AM
- Atmospheric lighting, fog, subtle film grain, and generated ambient tones
- A replayable opening chapter

## Run

This is a static website. Open `index.html` through a local static server, or enable GitHub Pages for the repository using the `main` branch and root folder.

Babylon.js is loaded from its public CDN. No API keys or paid services are required.

## Roadmap

1. Opening sequence and visual language
2. Character models and expressive animation
3. Scripted cinematic scenes and dialogue
4. Sound design, score, and subtitles
5. Full film timeline and export workflow

The story is presented as a film, not an interactive game.
